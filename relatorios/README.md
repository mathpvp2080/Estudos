# Relatórios de estudo

Ao final de cada sessão, criar um arquivo `AAAA-MM-DD-materia.md` com:

- duração e tema;
- o que foi explicado;
- exercícios e desempenho;
- pontos fortes e dificuldades;
- dúvidas;
- onde paramos;
- próximo passo.

Esses relatórios preservam o histórico. O resumo mais atual de cada disciplina fica em `materias/`.
